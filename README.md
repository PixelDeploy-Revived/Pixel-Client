# Pixel Client: Born Again!

> **Pixel Client: Born Again!** is developed with [MCP](http://www.modcoderpack.com/) and is based on [Eric Golde](https://github.com/egold555/)'s events, modules and cosmetics system.

## 🥇 The original one
**Pixel Client** is a PvP client for Minecraft 1.8.8. It became famous in 2019 because of its simple Minecraft-like GUIs, free wings and PvP mods. Today the project is discontinued: the last official version of Pixel Client is _beta v7.9_.

## 💡 The reborn
As Pixel Client fan and developer I decided to rewrite it from scratch with just one goal: revive the project.
For copyright reasons I sent an email to the [original developer](https://github.com/kiritodv), who gave me the permission and joined the project.

## 📦 Download
**Pixel Client: Born Again!** is available for **Premium** and **SP** (offline) players.

> Currently a dedicated launcher is not planned to be developed: the installation is manual.

### ⚙ How to install it
1. Download the ZIP from [releases](https://github.com/PixelDeploy-Revived/Pixel-Client/releases)
2. Press **Windows** + **R** and digit "%appdata%"
3. Open ".minecraft", then "versions"
4. Open the downloaded ZIP
5. Move "Pixel Client 1.8.9" into "versions"
6. Open your Minecraft launcher, select the version and enjoy it!
